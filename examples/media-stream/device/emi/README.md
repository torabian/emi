# Generated Emi C++ SDK (generic dialect)

Generated by the Emi compiler - do not edit by hand.

Portable ISO C++17: desktop/POSIX, ESP-IDF, and the Arduino framework all build
the same generated dto/action/enum headers unmodified. Every dto is a plain
value-semantics class (default-constructible, copyable, movable) with:

- `cJSON* ToJson() const` / `static T FromJson(const cJSON* json)` - the
  caller owns the returned cJSON tree from `ToJson()` and must `cJSON_Delete` it.
- `static T Parse(const std::string&)` / `std::string Dump() const` for the
  common "just give me a string" case.

Every generated action/remote function takes an `emi::EmiClientConfig&` (or uses
`emi::EmiClientConfig::Default()`) with a `transport` pointer you set once -
pick the `IEmiHttpTransport` implementation matching your platform:

| Platform          | Header                          | Notes                                  |
| ------------------ | -------------------------------- | ---------------------------------------- |
| Desktop/POSIX       | EmiHttpTransportCurl.hpp          | link `-lcurl`                              |
| ESP-IDF              | EmiHttpTransportEspIdf.hpp        | add `esp_http_client` to component REQUIRES |
| Arduino (ESP32/ESP8266) | EmiHttpTransportArduino.hpp    | needs the "HTTPClient" Arduino library    |

`method: reactive` actions use `emi::EmiWebSocketX` (EmiWebSocketX.hpp), a
minimal RFC 6455 client over `emi::IEmiByteStream` - EmiByteStreamPosix.hpp
(desktop + ESP-IDF) or EmiByteStreamArduino.hpp back it. See the doc comment on
EmiWebSocketX for its documented scope boundary (no fragmentation/permessage-deflate).

Raw binary (microphone / camera / sensor bytes): `socket->SendBinary(data, len)` and
`socket->onBinary` send/receive binary websocket frames, and EmiMediaFrame.hpp adds a
12 byte header (kind, seq, timestamp) plus `emi::EmiMediaSender` to multiplex audio and
video on one socket - the Go twin is `emigo.MediaFrame`. See examples/media-stream.

Build against the vendored cJSON (compile `cjson/cJSON.c` once into your program) -
same library the C target uses.
